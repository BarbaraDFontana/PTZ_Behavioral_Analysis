# PTZ Behavioral Analysis

Reproducible R workflow for behavioral data analysis and machine learning classification using DeepLabCut-derived features in translational neuroscience research.

## Overview

This repository contains scripts and workflows for:
- preprocessing behavioral tracking data,
- feature extraction,
- statistical analysis,
- visualization,
- random forest modeling,
- classification of experimental behavioral phenotypes.

The pipeline was developed for preclinical behavioral neuroscience applications using zebrafish experimental models.
